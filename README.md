# 分润规则后台原型（优坐标管理系统）

分润规则配置页的高保真原型，技术栈 Vue 3 + TypeScript + Vite + Element Plus。

在线预览：https://17611185912l-cmd.github.io/fenxiao/

## 页面功能

- 规则列表：规则名称搜索、启用/禁用筛选，列表内胶囊开关直接切换状态
- 有效分享时间：全局配置，以客户最后一次打开分享链接的时间为起点，在设定时长内下单才计入分享归因
- 新建 / 编辑规则：适用范围（含指定课程多选）、客户归因、结算时点
- 分润配置：按「参与人」分组，每组可配置多个返还层级（一级 / 二级 / 关系顶级），每个层级可独立设置计算方式（按比例 / 按金额）、分润值和「必须为合伙人」特殊情况
- 规则详情：字段信息、分润配置分组、创建人与最后更新人、创建时间与更新时间（精确到秒）
- 右侧页面说明：说明内容随列表 / 新建 / 编辑 / 详情状态联动切换

## 本地运行

```bash
npm install
npm run dev
```

## 发布说明

`docs/` 目录是 GitHub Pages 使用的构建产物，由下面的命令生成：

```bash
npx vite build --base=/fenxiao/ --outDir docs
```

源码改动后重新执行该命令并提交 `docs/`，线上预览即会更新。
